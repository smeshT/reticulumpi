FLRIG

About

FLrig allows for a couple more radio control options from the computer than the digital apps do by themselves. The frequency is a little easier to change from FlRig but it also allow for the remote use of the G90's TUNE function for antenna tuning.
If you decide to use FLrig you will need to ensure that the digital app you choose is set for FLrig. The radio settings for the digital apps are covered in the instructions for those apps.

Getting Started

To get started click the Start button for the digital app you want to use below.

Adjust Audio Levels

Radio Settings

- Config > Setup > Transceiver to bring up the Configuration window.
- Under the Xcvr branch, set the Rig to Xiegu-G90.
- Set Update to /dev/ttyUSB0.
- Set the Baud to 119200.
- Check the box for 1.
- Under the PTT-Generic branch, leave CW mode PTT unchecked.
- PTT on CAT Serial Port; CAT to SET, RTS to SET and DTR to OFF.
- RTS +12 and DTS +12 unchecked.
- PTT control on seperate serial port; Port to NONE.
