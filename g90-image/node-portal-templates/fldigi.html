Settings

User Settings

- File > Settings to open the settings window.
- Under the General tab, and the Station sub-tab:
set the Callsign and Grid Square fields to your callsign and grid square.

Radio Settings

- File > Settings
- Under the Radio tab, set the Rig Type to G90.
- Under the CAT Control sub-tab, set the Serial Port to /dev/ttyUSB0.
- Set the Rig Baud to 119200.
- Data Bits to 8 and Stop Bits to 1.
- Handshake to Default.
- Force Control Lines; DTR to Low and RTS to Low.
- Click Test CAT Settings. the button will turn green if the settings are correct.
- Then click Test PTT. The button will turn red while PTT is active and then back to gray when clicked again.
- Click OK to save the settings.

Audio Settings

- File > Settings
- Under the Audio tab Modulation Soundcard Input is: alsa_input class=usb-C-Media_Electronics_Inc _USB_Audio_Device-00.mono-fallback.
- output is: alsa_output class=usb-C-Media_Electronics_Inc _USB_Audio_Device-00.analog-stereo.
- Click OK to save the settings.
