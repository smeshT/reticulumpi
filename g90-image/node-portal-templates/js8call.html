Operation

- Change callsign and grid according to SOP
- Set the frequency (freq) to the pre-arranged frequency
- Set the mode to the JS8 normal for initial contact. Mode > JS8 (Normal...)
- Set the offset by clicking in the waterfall display in an area that is clear of signals.
- Type your outgoing message in the text box where it says to and hit Enter to transmit. Your message will turn red when it has been sent. JS8Call is time referenced so it may not send immediately when you hit Enter. It will wait for the next time slot to send the message.
- To reply to a message, click on the message and then type your reply in the outgoing message box.
- If the dynamic scale in the lower left is turning red frequently then the Input Level needs to be reduced. Click the PavuControl button above (restarts JS8Call) and adjust the input level for the USB audio device down until the dynamic scale is green and the pointer is hovering around 60-70.

Settings

User Settings. These will be changed frequently

- File > Settings to open the settings window.
- Under the General tab, and the Station sub-tab:
set the Callsign and Grid Square fields to your callsign and grid square.

Radio Settings. These are only for reference if something gets messed up.

- File > Settings
- Under the Radio tab, set the Rig Type to G90.
- Under the CAT Control sub-tab, set the Serial Port to /dev/ttyUSB0.
- Set the Rig Baud to 119200.
- Data Bits to 8 and Stop Bits to 1.
- Handshake to Default.
- Force Control Lines; DTR to Low and RTS to Low.
- Click Test CAT Settings. the button will turn green if the settings are correct.
- Then click Test PTT. The button will turn red while PTT is active and then back to gray when clicked again.
- Click OK to save the settings.

Audio Settings. For reference.

- File > Settings
- Under the Audio tab Modulation Soundcard Input is: alsa_input class=usb-C-Media_Electronics_Inc _USB_Audio_Device-00.mono-fallback.
- output is: alsa_output class=usb-C-Media_Electronics_Inc _USB_Audio_Device-00.analog-stereo.
- Click OK to save the settings.
